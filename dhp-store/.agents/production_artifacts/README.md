# Production Artifacts

This directory contains documents generated by the Autonomous AI Developer Pipeline.

| Artifact | Generated By | Description |
|---|---|---|
| `Technical_Specification.md` | @pm via `write_specs` | Feature specification (requires user approval) |
| `Implementation_Plan.md` | @fe/@be via `generate_code` | Phased implementation breakdown |
| `Walkthrough.md` | @fe/@be via `generate_code` | Post-implementation change log |
| `Audit_Report.md` | @qa via `audit_code` | Quality assurance findings |

> These files are ephemeral and overwritten each cycle. Commit them to Git only when they represent an approved, completed feature.
